# Стекло Проф • Премиальный анимированный редизайн

Готовый адаптивный демонстрационный сайт на HTML, CSS и JavaScript, созданный на основе открытой информации https://stekloproff.kz/ и **вашего исходного логотипа**. Живой сайт на домене не изменён.

## Что включено

- Оригинальный присланный логотип компании (аккуратно обрезан фон скриншота, **не заменён** другой эмблемой).
- Фирменная сине-белая визуальная система, крупный первый экран, фото шести видов услуг.
- Плавное появление блоков при прокрутке, блики на автостекле, анимированные hover-состояния карточек, скролл-индикатор, плавное появление модального окна, анимация фильтров.
- Автоматическое отключение анимаций при `prefers-reduced-motion: reduce`.
- Подбор автостекла и услуг; прямое открытие WhatsApp c заполненной заявкой на **+7 707 494 68 78**.
- Фильтры услуг «Все / Ремонт / Замена / Уход и защита».
- Список популярных марок и шесть моделей для подбора стекла. Выбор модели заполняет форму.
- Переключение языка RU/KZ/EN; мобильное меню; FAQ; контактные ссылки.
- Адаптивность, SEO-метаданные, структурированные данные AutoRepair.
- Никаких тяжёлых UI-фреймворков. Открывается как обычный статический сайт.

## Файлы

- `index.html` — основной сайт.
- `styles.css` — исходная адаптивная структура.
- `premium.css` — фирменный дизайн и анимации.
- `script.js` — основная логика сайта (форма, фильтр, язык, меню).
- `motion.js` — анимации с учётом доступности.
- `assets/logo-original.png` — ваш логотип, обрезанный из присланного изображения.
- `assets/*.jpg` — **демонстрационные сгенерированные фото**, а не реальные работы сервиса.

## Как открыть

Откройте `index.html` из папки после распаковки ZIP. Для пробного просмотра есть отдельный самодостаточный файл `stekloproff-animated-preview.html`, в котором стили, скрипты и изображения встроены внутрь.

## Что проверить перед запуском на домене

1. Подтвердить цены и условия гарантии. На действующем сайте для ремонта скола встречаются **«от 3 000 ₸»** и **«5 000 ₸»**. В этом макете указан ориентир от 5 000 ₸ — для публикации нужна актуальная цена от владельца.
2. Заменить демонстрационные изображения реальными работами и по возможности предоставить отдельный оригинал логотипа в SVG или PNG высокого разрешения вместо скриншота.
3. Проверить телефон, адрес и актуальность услуг.
4. Если нужен приём заявок в CRM или собственная база заявок, отдельно подключить имеющийся backend. В макете **заявка не хранится и не отправляется на сервер**, а только открывает WhatsApp.
5. Перед заменой действующего сайта сохранить резервную копию и убедиться, что не потеряны подключённые CRM, аналитика и служебные страницы.
